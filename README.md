# Ares - Control Maestro

Aplicación web de IA con chat de voz, video en vivo y control del sistema.

## Características

- **Chat de Voz**: Reconocimiento de voz PTT + síntesis de voz
- **En Vivo**: Cámara + Compartir Pantalla
- **Archivos**: Explorador de archivos con vista previa
- **Gestor de Tareas**: Crear y administrar tareas
- **Notas**: Notas rápidas
- **Enlaces**: Enlaces rápidos

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm start
```

Luego abre: http://localhost:3000

## Requisitos

- Node.js 18+
- Navegador Chrome/Edge (para voz y cámara)
